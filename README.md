# The Overnight Edition — Friday 20 November 2026

A dark-edition one-page newspaper that sums up a whole day of world news in a
single 1024x1024 picture: 40 stories from 7 regions, every one of them dated
Friday 20 November 2026. Thirteen stories are pictured as cards with original
flat drawings — Kyiv's bridges, Cyclone Akvan's landfall, the Asian AI
sell-off, the UK-EU reset deal and more — and 27 further stories run as
numbered briefs. A locator map pins the 13 pictured stories and dots the
briefs on real country outlines. The page also carries a UTC timeline of the
day, a "Day in Numbers" strip, per-region story counts and a date check that
names the Thursday stories deliberately left out. A source is named beside
every story, in each card's deck and at the end of each brief. The image is
produced by a deterministic Pillow program (`draw.py`, standard library plus
PIL only, no network); `main.py` copies the rendered `entry.png` to the
output directory.
